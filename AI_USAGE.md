# Generative-AI contribution statement

This statement documents the use of generative AI in the development and
maintenance of this repository. It is intentionally separate from software
authorship and from the scientific citations in `CITATION.cff`.

| Activity | AI used |
|---|---:|
| Asking the research question | No |
| Coming up with the approach | No |
| Proof development | No |
| Writing and exposition | No |
| Code development | Yes |
| Checking for bugs | Yes |
| Other supporting tasks | Yes |

## Details

OpenAI ChatGPT and Codex were used to assist with code drafting and
refactoring, bug identification, test generation and revision, repository
organisation, README and developer-documentation maintenance, and preparation
of reviewable GitHub changes. Model labels varied across development sessions;
not every historical model-version identifier was retained.

The `Writing and exposition` entry refers to the scientific manuscript and its
scientific argument, not to repository documentation. Repository organisation
and developer-facing documentation are reported under `Other supporting
tasks`.

Generative AI was not used to define the research question, choose the physical
models or scientific priors, set the scientific interpretation, develop
mathematical proofs, or write the scientific exposition of a paper. All
AI-assisted source code, tests, numerical outputs, and documentation were
reviewed by the author. Scientific assumptions, validation criteria, and the
interpretation of results remain the responsibility of the author.

AI systems are not authors or software contributors in `CITATION.cff`.
